# Landing Turismo

Landing page turística interactiva desarrollada con Vite, HTML, CSS y JavaScript.  
El proyecto presenta destinos turísticos de Centroamérica con diseño moderno, animaciones, modo oscuro y tarjetas dinámicas.

---

## Tecnologías utilizadas

- HTML5
- CSS3
- JavaScript ES6
- Vite
- GitHub Pages

---

## Características

- Diseño responsive
- Navbar dinámica
- Modo oscuro
- Tarjetas flip interactivas
- Destinos generados dinámicamente con JavaScript
- Validación de formularios
- Animaciones al hacer scroll
- FAQ interactivo
- Contadores animados

## Instalación

Clonar el repositorio:

```bash
git clone https://github.com/gemaortizprivados23-lgtm/landing-turismo.git
```

Entrar al proyecto:

```bash
cd landing-turismo
```

Instalar dependencias:

```bash
pnpm install
```

Ejecutar proyecto:

```bash
pnpm dev
```

---

## Build de producción

```bash
pnpm build
```

---

## Deploy GitHub Pages

```bash
pnpm deploy
```

---

## Configuración Vite

```js
import { defineConfig } from 'vite'

export default defineConfig({
  base: '/landing-turismo/'
})
```
